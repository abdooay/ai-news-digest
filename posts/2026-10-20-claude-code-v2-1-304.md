## What changed

Claude Code is Anthropic's command-line coding agent. Version 2.1.304 shipped with these changes:

- **Usage limit warning on resume.** On Pro and Max plans, resuming an inactive conversation now warns you first if doing so would use a noticeable share of your rolling 5-hour usage limit. You can resume anyway, or start a new conversation instead (Claude can still look up the old one if you refer to it).
- **New `/auto-mode-setup` command.** "Auto mode" is Claude Code's feature that checks whether your tool calls are safe before running them. This new guided setup reads your project and recent sessions to teach auto mode about your specific environment. It now also works on Bedrock, Vertex, Foundry, the Claude apps gateway, and sessions with telemetry turned off.
- **New `/claude-api managed-agents-secure` command.** For Managed Agents (Anthropic's server-hosted agents), this checks an agent's settings against Anthropic's published security guide, without changing anything.
- **Safer `rm -r` on mounted drives.** Deleting a mounted drive or the top level of one (like `/Volumes`, `/media`, or WSL's `/mnt/c`) now triggers the same safety confirmation prompt that deleting something like `/Applications` already gets.
- **Mod permission changes.** A mod (a small customization Claude Code can run) can now mark a `tool.check` answer with `decider: "person"`, meaning only a human — through the permission dialog or a host's own callback — can approve that action; if no person is available to ask, it's refused with the mod's stated reason.
- **Several reliability fixes**, including: organization policy no longer waiting up to an hour to refresh after you approve an API key at startup; a fix for a plugin keeping a headless run going past its turn or time limits by spawning subagents; and a fix for subagents sometimes forgetting recent work when messaged or resumed right after finishing.
- **Code Review changes.** Organizations using Claude's Code Review feature can now choose a review depth — Quick, Standard, or Deep — at the org level or per repository, and can opt to review every repository in a GitHub org automatically, including ones added later.

## Why it matters

The usage limit warning helps avoid an unpleasant surprise: resuming an old, large conversation that quietly eats most of your remaining 5-hour quota. The `rm -r` safety prompt closes a gap where deleting a whole mounted drive wasn't treated as seriously as deleting a system folder — worth knowing if you script cleanup commands. Teams running Code Review get more control over how deep automated reviews go, which matters for balancing thoroughness against noise and cost.

## How to use it

- Update with `claude update`, or through your package manager, to get these changes.
- Run `/auto-mode-setup` to let Claude Code learn your project's environment for auto mode.
- Run `/claude-api managed-agents-secure` to check a Managed Agents agent's settings against Anthropic's security guide.
- Org owners can set Code Review depth (Quick/Standard/Deep) globally or per repository in Code Review admin settings.
