## What changed

Hex, a data analysis platform, described how it uses GPT-6 Astra (OpenAI's model) inside its "agentic" data platform — one where the AI can work through multi-step analysis tasks. According to Hex co-founder and CTO Caitlin Colgrove, data visualization has historically been a weak spot for AI models, but GPT-6 Astra can build more complex, interactive outputs: dashboards, trend analyses, and geographic breakdowns, paired with written explanations of the findings.

Hex says the model handles the technical work of complex data visualization (including geospatial, i.e. map-based, visualizations) and, importantly, checks its own results — verifying that numbers make sense, that the analysis actually answers the question asked, and that it lines up with the underlying business goal, rather than just producing a chart on request.

## Why it matters

A chart that looks right but contains a data error can be worse than no chart at all, since it's easy to trust visually. Hex's description points to something beyond "make a graph" — a model reviewing its own analytical output before handing it to a user is a meaningful reliability improvement for anyone using AI to analyze real data, especially in fast-moving business reporting where a bad number can lead to a bad decision.

## How to use it

This is a description of how GPT-6 Astra performs inside Hex's existing agentic data platform — there's no separate setup step described here. Hex customers using its platform get the benefit automatically as the underlying model.
