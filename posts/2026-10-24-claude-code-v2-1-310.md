## What changed

Claude Code is Anthropic's command-line coding agent. Version 2.1.310 adds:

- A new **Monitor tool**, plus support for plugin monitors (small watchers that plugins can register) on Claude Platform on AWS (Bedrock), Google Vertex AI, and Microsoft Foundry — not just the direct Anthropic API as before.
- Enterprise custom-role controls for cloud sessions and Remote Control (Claude Code sessions you can manage from your phone or another device), plus a file picker for choosing a setup script.

It also fixes several bugs:
- Requests failing behind some network gateways that reject certain "beta" API values or mid-conversation system messages.
- Compaction (the process where Claude Code summarizes old conversation to save space) breaking after a "prompt too long" error.
- A background cleanup process that was deleting recently created files it shouldn't have touched.
- A batch of VS Code, Claude Tag (Claude in Slack), and `/code-review` fixes.

## Why it matters

The Monitor tool and plugin monitors give plugin authors a way to watch for events (like a background task finishing) without polling — and this release extends that capability to teams running Claude Code through Bedrock, Vertex, or Foundry instead of the direct API. The gateway and compaction fixes matter most for teams running Claude Code behind a corporate proxy or network gateway, or anyone who hit a stuck or broken session after a "prompt too long" error. The deleted-files fix is a real bug fix — a background cleanup routine was removing files it should have left alone.

## How to use it

- Update with `claude update`, or through your package manager, to get this release.
- No configuration changes are required for the bug fixes.
- Plugin authors can look at the Monitor tool docs to add event-driven monitors; this now works on Bedrock, Vertex, and Foundry deployments too.
- Enterprise admins managing cloud sessions or Remote Control now have custom-role controls available in their settings.
