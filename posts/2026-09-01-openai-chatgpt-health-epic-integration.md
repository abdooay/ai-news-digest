## What changed

On September 1, 2026, OpenAI announced that healthcare organizations can connect their Epic electronic health record (EHR) systems to ChatGPT for Healthcare. Epic is EHR software used by hospitals and clinics; OpenAI says it holds records for more than 325 million patients worldwide.

With the integration, clinicians can:
- Pull information from appointment notes, lab results, medications, and specialist documentation.
- Ask questions across a patient's full record — for example, to identify what's changed since a previous visit, or to prepare for an upcoming appointment.
- Review a patient's history and build a clinical timeline directly inside ChatGPT.

The connection is **read-only**: ChatGPT can retrieve and analyze patient data but cannot write anything back into the patient's chart.

Alongside this, OpenAI introduced a **Healthcare Public Data** plugin that connects ChatGPT to nine public healthcare sources, including ClinicalTrials.gov, CMS Coverage, RxNorm, DailyMed, and PubMed — so healthcare teams can search things like trial eligibility, medication identifiers, and coverage policies without visiting each database separately.

OpenAI says it evaluated the system with physicians across 27 clinical use cases (such as pre-visit review and medication review), covering 4,363 evaluations, and that physicians rated 99.1% of responses as safe. The integration is built to work within HIPAA (the US federal law governing patient data privacy).

## Why it matters

Before this, a clinician using ChatGPT for a patient question would have to manually copy information out of the EHR system first. Direct, read-only access removes that manual step and lets ChatGPT reference the actual record. The read-only design is a meaningful safety boundary — the AI cannot alter the patient's chart, only read from it and summarize or answer questions about it.

## How to use it

- This is for healthcare organizations using ChatGPT for Healthcare with an Epic EHR system — an org admin needs to set up the connection.
- The Healthcare Public Data plugin is available to eligible Clinicians users in the United States, and works without any organization-side setup.
- OpenAI states this tool is not meant for diagnosis or treatment decisions — it's for looking up and summarizing existing information.
