## What changed

Claude Code, Anthropic's command-line coding agent, released version 2.1.219 on July 24, 2026, followed by version 2.1.220, described only as "bug fixes and reliability improvements" with no further detail published.

**v2.1.219 highlights:**

- **Claude Opus 5 is now the default Opus model** (model ID `claude-opus-5`), replacing Opus 4.8 as the default. It brings the same 1M-token context window as on the API, and fast mode (faster responses at a higher price) now costs $10 per million input tokens and $50 per million output tokens on Opus 5.
- **`sandbox.network.strictAllowlist` setting:** when set, sandboxed commands (commands Claude runs in an isolated environment) can only reach hosts you've explicitly allowed — anything else is silently denied instead of triggering a permission prompt.
- **`DirectoryAdded` hook:** a new hook (a script Claude Code runs automatically at a specific point) that fires whenever a new working directory is registered mid-session, such as through `/add-dir`.
- **Deeper subagent nesting:** subagents (helper agents Claude spawns to do part of a task) can now spawn their own subagents up to 3 levels deep by default, up from 1. Set the environment variable `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` to turn this off and go back to the old limit.
- **`workflowSizeGuideline` setting:** lets you set the advisory size limit for Dynamic workflows (how many agents a workflow aims to use) from any settings file, rather than only through the `/config` menu.
- **MCP connection diagnostics:** `claude mcp list` and `/mcp` now show the HTTP status and error text when a Model Context Protocol (MCP) server fails to connect, plus a warning if an MCP config value has hidden leading or trailing whitespace.
- **Fast mode changes:** Opus 4.7 no longer supports fast mode at all; `/fast` now applies only to Opus 5 and Opus 4.8.
- **Various fixes:** `claude -p` (non-interactive mode) no longer drops an already-generated answer if the connection fails mid-stream; a stale cache no longer mislabels the Fable model row as "requires usage credits"; the `/model` picker correctly shows "Opus (1M context)" instead of a plain "Opus" label; copy-on-select inside GNU screen no longer pastes base64 text; and several Vim-mode, screen-reader, and Windows-specific bugs were fixed.

**v2.1.220:** Anthropic's changelog lists this release only as "bug fixes and reliability improvements," with no individual items published.

## Why it matters

Opus 5 becoming the Claude Code default means anyone running Claude Code without pinning a specific model now gets the newer, more capable model automatically — worth knowing since Opus 5's fast mode is priced differently ($10/$50 per million tokens) than before. The stricter sandbox network allowlist and the `DirectoryAdded` hook are aimed at teams who need tighter control over what a sandboxed Claude Code session can reach or do. The subagent nesting increase (1 to 3 levels) means more complex multi-agent workflows can now run without hitting the old depth limit — useful if you build custom agent teams, but worth watching if you rely on the shallower default for cost or predictability reasons.

## How to use it

- Update with `claude update`, or through your package manager, to get both v2.1.219 and v2.1.220.
- To restrict sandboxed network access to an allowlist, set `sandbox.network.strictAllowlist` in your settings.
- To catch new working directories mid-session, add a `DirectoryAdded` hook.
- To go back to single-level subagent spawning, set `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1`.
- To set a Dynamic workflow size guideline outside `/config`, add `workflowSizeGuideline` to any settings file.
- No action needed for the other fixes; they apply automatically after updating.
