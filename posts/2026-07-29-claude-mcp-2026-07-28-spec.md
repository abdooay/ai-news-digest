## What changed

On July 28, 2026, Anthropic announced that Claude is adopting the newest version of the Model Context Protocol (MCP), dated 2026-07-28. MCP is the open standard that lets AI models like Claude connect to outside tools and data sources, called "MCP servers." This is the fifth version of the spec, and Anthropic calls it the biggest revision since MCP launched.

Three main changes:

- **Stateless core.** Until now, MCP was a "stateful" protocol, meaning a client and server had to keep a continuous back-and-forth connection open. The new spec moves to a plain request/response model, similar to normal web APIs. This lets MCP servers run on serverless and edge infrastructure (systems that only run code when a request comes in, rather than a server that's always on), which is simpler to scale.
- **Stronger sign-in.** The spec updates how MCP handles OAuth 2.0 and OIDC, the standard technologies websites use for "sign in with X" login. This lets MCP servers plug into enterprise identity systems like Microsoft Entra or Okta without workarounds.
- **Versioned extensions.** Two features, MCP Apps (interactive UI shown inline in a conversation) and Tasks (long-running work), now ship as formal, versioned add-ons to the core spec, so they can keep evolving without changing the base protocol.

Anthropic also says MCP has passed 400 million monthly SDK downloads, a fourfold increase over the past year, and that Claude's connector directory now lists more than 950 MCP servers.

Alongside the spec update, Anthropic is rolling out related Claude features: MCP Apps for inline interactive UI, enterprise-managed authentication for zero-touch admin setup, observability dashboards showing connector performance, and MCP tunnels (a research preview) for connecting to private networks without exposing a public endpoint.

## Why it matters

If you build or run MCP servers, the stateless core removes the need to keep a persistent connection alive, which makes it cheaper and simpler to host a server, especially on serverless platforms. The improved OAuth/OIDC support matters most for companies that need MCP servers to work with their existing corporate login systems rather than a separate credential setup. The versioned extensions framework means new capabilities like interactive UI and long-running tasks can keep improving without breaking servers built against the base spec.

For everyday Claude users, this mostly happens behind the scenes: Anthropic says support is "rolling out across Claude products soon," with no announced deadline for the older protocol version.

## How to use it

- Read the spec at [modelcontextprotocol.io/specification/2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/) and the SDKs at [modelcontextprotocol.io/docs/sdk](https://modelcontextprotocol.io/docs/sdk) if you build MCP servers.
- To submit or update a connector for Claude, see [Anthropic's connector submission docs](https://claude.com/docs/connectors/building/submission).
- MCP tunnels are in research preview; details are in the [MCP tunnels overview](https://platform.claude.com/docs/en/agents-and-tools/mcp-tunnels/overview).
- Anthropic did not publish a required upgrade step or opt-in setting for end users — this is a server- and platform-side change that rolls out over time.
