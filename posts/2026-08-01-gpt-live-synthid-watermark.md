## What changed

On July 31, 2026, OpenAI said audio generated by GPT-Live — the voice model behind ChatGPT Voice and the OpenAI API's realtime voice features — now includes SynthID watermarking. SynthID is a watermarking technique (originally built by Google DeepMind) that embeds a signal in generated media that's not audible to a listener but can be detected by software.

OpenAI's public verification tool, at openai.com/research/verify/, can check whether a supported audio file carries this watermark and was generated by OpenAI. OpenAI also added API access for this verification, so developers and organizations can check audio provenance programmatically inside their own workflows, rather than only through the web tool.

OpenAI frames this as part of a broader effort to make AI-generated content easier to identify.

## Why it matters

As AI-generated voice gets harder to tell apart from a real person speaking, a way to check "was this made by an AI model" matters for trust — for example, verifying a voice clip in a dispute, or an app that wants to flag AI-generated audio automatically. Because the watermark is invisible to a listener, it doesn't change how the audio sounds; it's a technical marker for tools to check separately.

This only covers audio made through GPT-Live (ChatGPT Voice and the related API). It doesn't cover audio made by other tools, older recordings, or audio that's been heavily edited or re-encoded, since watermark techniques can be degraded by such changes.

## How to use it

- To check a single file by hand, use OpenAI's public verification tool at openai.com/research/verify/.
- To check audio programmatically in your own app, use the new API access for verification that OpenAI added alongside this update. OpenAI's announcement doesn't give exact endpoint or parameter names, so check OpenAI's API documentation for the verification API details before integrating it.
