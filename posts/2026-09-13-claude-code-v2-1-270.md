## What changed

Claude Code, Anthropic's command-line coding agent, shipped v2.1.270. It contains one fix: read-only git commands (like `git status` or `git log`) run through the Bash tool were unexpectedly asking for permission again after a session had been running for a while. This was a regression introduced in the previous release, v2.1.269.

## Why it matters

Claude Code normally allows read-only git commands to run without asking, since they can't change anything. The v2.1.269 bug meant that in sessions that stayed open a long time, Claude Code would start prompting for permission on these safe commands anyway, adding friction for no safety benefit. v2.1.270 restores the expected behavior.

## How to use it

Update with `claude update`, or through your package manager. The fix applies automatically — no configuration needed.
