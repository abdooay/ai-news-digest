## What changed

On September 3, 2026, OpenAI announced "Daybreak for Frontline Defenders," a program that gives $1 billion worth of subsidized access to its Daybreak cybersecurity AI tools to organizations that protect essential services but don't have big security budgets.

"Frontline defenders" here means groups like:
- Water and wastewater system operators
- Electric grid operators
- State and local governments
- Community and regional banks
- Nonprofits and open-source software maintainers

OpenAI says more than 2,000 organizations already use Daybreak across cybersecurity, defense, and law enforcement. The Daybreak tools come in two tiers: "Daybreak Blue" for everyday defensive work, and "Daybreak Red," which gives approved organizations access to more specialized, more sensitive cyber models for tougher jobs. These tools can review old ("legacy") code, look for suspicious activity, find vulnerabilities, and write fixes that have been tested.

OpenAI also says it will make the tools available through more than 35 existing enterprise security products, via something it calls the Daybreak Defense Network, so defenders can get AI help inside tools they already use instead of adopting something new.

## Why it matters

Small, under-funded organizations — a rural water utility or a community bank, for example — often can't afford dedicated cybersecurity staff or expensive AI-powered security tools. This program is meant to close that gap by making the same kind of AI cyber-defense tools that large enterprises use available to them at reduced or no cost. If it works as described, smaller organizations that run critical infrastructure could get real help finding and fixing security holes before attackers do.

## How to use it

- If your organization fits one of the eligible categories (utility, grid operator, local government, small bank, nonprofit, open-source maintainer, or similar resource-constrained defender), visit OpenAI's Daybreak website to check eligibility and apply for access, training, and technical support.
- OpenAI says the $1 billion in subsidized access is intended to be used over the next six months, so apply promptly if you think you qualify.
