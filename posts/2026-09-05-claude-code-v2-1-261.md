## What changed

Claude Code is Anthropic's command-line coding agent. Version 2.1.261 is mostly bug fixes, plus a few new settings and commands:

**New features:**
- Two new settings, `bashOutputMaxChars` and `taskOutputMaxChars`, let you raise the limit on how much output from Bash commands or subagent tasks gets kept, up to 128,000 characters.
- A new `--append-subagent-system-prompt-file` flag lets you pass a large system prompt for a subagent from a file, instead of typing it inline.
- A new `/skill-doctor` command reports which of your installed skills aren't being used, and how much context space they cost.
- `/status` and `claude doctor` now explain when an organization policy fails to load, instead of failing silently.

**Notable fixes:**
- Fixed a bug where characters could land out of order when typing or pasting quickly, or when holding down a key.
- Fixed `/add-dir <subdirectory>` incorrectly reporting an error on network-mounted (`/net` automount) working directories.
- Fixed the Bedrock (Amazon's hosted version of Claude) setup wizard hanging or misreporting model availability behind TLS-inspecting corporate proxies.
- Fixed cloud-plugin conflicts where a plugin installed from a marketplace clash with one force-enabled by settings.
- Fixed being unable to delete characters right before an inline image attached to a prompt.
- Fixed session resumption dropping hook output when it happened around parallel tool calls.
- Several Remote Control (controlling a Claude Code session from another device) fixes: more accurate permission-mode display, status indicators that no longer get stuck after stopping, sessions that now respond immediately to a Stop command, no more duplicate uploads when switching devices mid-session, and better handling of corporate TLS-inspecting proxies.
- Fixed `gcpAuthRefresh` opening a browser window unnecessarily when checking Google Cloud credentials was slow.

## Why it matters

If you've hit truncated Bash or subagent output, the two new max-chars settings give you a way to raise that ceiling instead of losing information. `/skill-doctor` is useful if you've installed several skills over time and aren't sure which ones are actually loaded and costing you context space — it tells you which to remove. Most of the rest are reliability fixes: the typing-order bug and the several Remote Control fixes are the kind of small annoyances that build up if you use Claude Code daily.

## How to use it

- Update with `claude update`, or through your package manager.
- Run `/skill-doctor` to see unused skills and their context cost.
- Add `bashOutputMaxChars` or `taskOutputMaxChars` to your settings if you need more than the default output kept.
- Use `--append-subagent-system-prompt-file <path>` when starting a subagent with a long system prompt.
- No action needed for the bug fixes — they apply automatically after updating.
