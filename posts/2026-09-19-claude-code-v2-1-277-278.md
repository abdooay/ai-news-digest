## What changed

Claude Code, Anthropic's command-line coding agent, shipped v2.1.277 and v2.1.278.

**v2.1.277** is mostly bug fixes, plus one notable feature:
- **AGENTS.md support**: in a project that has no `CLAUDE.md` file, Claude Code now reads an `AGENTS.md` file instead for project instructions. This can be changed under "Project instructions" in `/config`. Not yet available on Bedrock, Vertex, or Foundry (Anthropic's cloud-provider integrations).
- Gateway (proxy) improvements: a new `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` setting for setups where a forward proxy is the only way out to the internet, and an optional `headers:` map to send fixed headers to a proxy.
- A long list of fixes: sessions that could hang with no result after an internal error now report the error and exit properly; a bug where an empty text block in an earlier turn broke every later request; users being unexpectedly logged out when an older bundled Claude Code build ran on the same machine; several startup crashes tied to malformed config files; and various Grep, Edit, and Write tool error-reporting fixes.
- VS Code extension: a sign-out menu option, visibility into background shells and running tasks, a "Copy response" button, and session cost/usage display.

**v2.1.278** made one change: auto mode (Claude Code's automatic effort-level selection) now defaults to running its classifier on Anthropic's servers instead of the client, for Claude API, Enterprise, Bedrock, Vertex, Foundry, and gateway users. The server-side classifier doesn't charge for the extra "classifier overhead" tokens the old client-side version used. `/status` now shows a row indicating whether a session's classifier is running server-side. Bedrock, Vertex, Foundry, and gateway users can opt out with `CLAUDE_CODE_AUTO_MODE_SERVER=0`; Claude Code will warn if a session falls back to the billed client-side classifier.

## Why it matters

AGENTS.md is a project-instructions format used by several coding agents beyond Claude Code; supporting it means a project can define instructions once and have them picked up by multiple tools, instead of needing a Claude Code-specific file. The auto mode change in v2.1.278 is a straightforward cost reduction for anyone using auto mode on the Claude API or through Bedrock/Vertex/Foundry/gateways — it removes a charge that existed only because the classifier used to run on your own tokens.

## How to use it

- Update with `claude update`, or through your package manager, to reach v2.1.278.
- To use AGENTS.md, add the file to a project that has no CLAUDE.md, or change the setting under "Project instructions" in `/config`.
- Check `/status` to see whether your session's auto mode classifier is running server-side.
- On Bedrock, Vertex, Foundry, or a gateway, set `CLAUDE_CODE_AUTO_MODE_SERVER=0` to opt out of the server-side classifier.
