## What changed

Claude Code is Anthropic's command-line coding agent. Version 2.1.309 is a reliability and security-hardening release — no major new features, but a large batch of fixes. Highlights:

**Sandbox and permissions** (the sandbox is the restricted environment Claude Code can run shell commands in without asking permission each time):
- Several commands that could previously slip past sandbox or permission rules are now caught: compound commands that `cd` before running `git`, `sed -i` edits, locale-prefixed and zsh arithmetic commands inside worktrees, and Bash redirects that could write to a denied path through a subshell.
- Disabled MCP (Model Context Protocol) servers no longer get silently reconnected by a later permission prompt.
- `claude ultrareview` now requires workspace trust by default (scripts can opt out with `--trust-workspace` or an environment variable).
- In bypass mode on the Desktop app and VS Code, dangerous `rm`/`rmdir` commands are now denied outright instead of prompted.

**Sessions and CLI:**
- Oversized nested `CLAUDE.md` files (project instruction files) now load only their beginning instead of causing repeated, wasted compaction (compaction is when Claude Code summarizes old conversation to save space).
- Messages from other agents or Claude Desktop sessions are no longer lost or delayed on reconnect.
- `/rewind` (which lets you undo changes) now also lists turns changed by `/code-review --fix`, subagents, or shell commands.
- Sessions renamed with `/rename` stay renamed after reload.

**Other areas:** several VS Code fixes (blank chat panel after a stale cache, long slash-command messages not wrapping), cloud-session UI fixes, and Slack ("Claude Tag") fixes for drafts posting to the wrong place and stale approval cards.

## Why it matters

Most of these are edge-case security tightening: specific ways a command could previously dodge the sandbox or a permission rule that are now closed. If you rely on the sandbox for safety when running Claude Code on untrusted repos or commands, this release narrows the gap between what you'd expect to be blocked and what actually is. The CLAUDE.md fix matters if you have a large project instructions file — it stops Claude Code repeatedly re-summarizing the conversation because of it.

## How to use it

- Update with `claude update`, or through your package manager, to get this release.
- No configuration changes are needed — these are fixes, not new settings.
- If you were relying on `claude ultrareview` running without workspace trust in a script, add `--trust-workspace` or set the corresponding environment variable.
