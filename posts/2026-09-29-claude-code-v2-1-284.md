## What changed

Claude Code (Anthropic's command-line coding tool) shipped version 2.1.284. The headline change is that Claude Sonnet 5.5 (`claude-sonnet-5-5`) is now the default model, with support for its 1-million-token context window and improved pricing.

Other notable additions:
- Auto mode (Claude Code's permission system that decides what it can do without asking) now offers a "Yes, but ask again next time" option when it wants to read a file outside your project folders — so you can allow that one read without opening the door to every future one.
- `/usage` and the status line now show exact dollar amounts spent against your spend limit, for teams using a managed Claude apps gateway.
- `/mcp reconnect all` lets you retry every MCP (Model Context Protocol, the standard Claude Code uses to connect to external tools) server that failed to connect, in one command instead of one at a time.

Several bug fixes address broken sessions:
- A bug that showed raw errors like "JSON Parse error" or wrote the literal word "undefined" into a response, instead of retrying, is fixed.
- "Prompt is too long" errors that kept happening even after Claude Code compacted (summarized) the conversation are fixed — it now compacts a second time, keeping less recent history, until the request fits.
- A crash in the Agent SDK (the toolkit developers use to build on Claude Code) when a message contained an image with malformed data is fixed; that image is now replaced with an explanatory note instead of crashing every later turn.
- MCP tool calls in a resumed session no longer fail with "No such tool available" if the server was still reconnecting — Claude Code now waits up to 10 seconds for it.

## Why it matters

The default-model switch means most people using Claude Code without pinning a model will automatically start getting Sonnet 5.5's speed and accuracy improvements. The reliability fixes matter for anyone who has hit a stuck or broken session mid-task — especially the compacting fix, since "prompt too long" errors that persisted after compacting could previously strand a long-running session with no way to continue.

## How to use it

- Update Claude Code to v2.1.284 or later (it self-updates by default, or run your package manager's update command).
- If you want to keep using a different model, set it explicitly with `/model` or your config — the new default only applies when no model is pinned.
- Try `/mcp reconnect all` if you have several MCP servers and one or more failed to connect at startup.
