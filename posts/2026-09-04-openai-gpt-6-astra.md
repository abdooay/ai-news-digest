## What changed

On September 3, 2026, OpenAI announced GPT-6 Astra, calling it its most capable and best-aligned model yet. OpenAI says it sets new highs on several benchmarks:

- Computer use and automation: state-of-the-art results on "Agents' Last Exam," AutomationBench, and ScreenSpot Pro.
- Reasoning: top scores on FrontierMath Tier 4, ARC-AGI 3, and TerminalBench-4.0.
- Science: leading results on Terminal-Bench Science 0.1 and HealthBench Pro.
- Safety: the model now refuses 94% of disallowed cybersecurity-related requests in OpenAI's testing, up from lower rates on earlier models.

Technical details OpenAI published:
- Context window: 1,050,000 tokens.
- Maximum output: 128,000 tokens.
- Knowledge cutoff: April 30, 2026.
- API pricing: $10 per million input tokens, $1 per million cached input tokens, $12.50 per million tokens for cache writes, and $50 per million output tokens.

Rollout is staged. GPT-6 Astra first went to a limited set of organizations in OpenAI's Trusted Access Program. OpenAI says wider availability — through ChatGPT Plus, Pro, Business, and Enterprise plans, plus the API — is coming "in the coming days."

## Why it matters

This is a full model generation change (GPT-5.6 to GPT-6), not a minor update. The pricing is notably higher than GPT-5.6 Sol: $10/$50 per million input/output tokens for Astra versus $4/$20 for Sol after its recent price cut. Anyone budgeting API costs should check whether Astra's benchmark gains are worth the price difference for their use case, or whether a cheaper model in the lineup still fits.

The staged rollout also means most users won't get access immediately — ChatGPT and API users should expect a wait before Astra appears in their account.

## How to use it

- Watch your ChatGPT plan (Plus, Pro, Business, or Enterprise) for Astra to appear; OpenAI has not given an exact date beyond "coming days."
- API access will roll out the same way; check the OpenAI API model list once available.
- If you're already testing it, note the 1,050,000-token context limit and 128,000-token output cap when designing prompts.
