## What changed

Claude Code is Anthropic's command-line coding agent. Version 2.1.312 is a fix-and-polish release. Notable changes:

- **Large files**: previously, if Claude only read the start of a very large `CLAUDE.md` (project instructions file), rules file, or `@`-included file, a `Write` could overwrite the whole thing based on that partial read. Now, `Write` asks Claude to read the whole file first, or edit it in place instead.
- **Sessions**: fixed a rare bug where, after resuming a terminal session, the first reply you got back could be lost the next time you resumed.
- **Commands**: fixed a bug where one invalid command name could block all commands from loading — this could leave `claude -p` (non-interactive mode) with no output at all.
- **Skills**: fixed per-directory and `paths:`-scoped skills going undetected after running a Bash command that `cd`s into a deeper nested git repository.
- **PDFs**: fixed intermittent `Read` failures on PDF pages that happened when old session files were being cleaned up at the same time.
- **Hooks**: prompt and agent hooks (scripts that run on certain events) now run at most 24 at a time per session, with extra limits on ones that wait a long time. Hook timeouts under 1 second now count as 1 second.
- **Gateway**: adds an OIDC (a login/identity standard) setting so the Claude apps gateway can identify people using a claim other than the standard `sub` field — for example, Microsoft Entra ID's `oid` claim.
- **Subagents**: `autoCompactWindow`, a setting that controls when a subagent's conversation gets auto-summarized, can now lower that window for subagents (previously it had no effect there). It still can't raise it above the default.
- **Effort level display**: the spinner, telemetry, and transcripts now show the effort level actually being used for a task, rather than one that was only picked partway through.
- **Third-party model providers**: Bedrock, Vertex, Foundry, and Mantle now use Claude Code's shorter system prompt when given an unrecognized model name. Set `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` to keep the full prompt instead.

Several smaller fixes also landed for Vim mode, the VS Code extension, cloud sessions, Remote Control, and Claude Tag (Claude in Slack).

## Why it matters

The large-file `Write` fix matters most if you keep a sizeable `CLAUDE.md` or rules file: it closes a way Claude could previously destroy most of a file's content by writing back only what it had read. The command-loading fix matters for anyone scripting Claude Code with `claude -p`, since one bad command definition could previously have silently broken every command and produced no output. The hook concurrency limit is worth knowing about if you run many hooks per session — hooks beyond the cap, or ones stuck waiting a long time, are now throttled.

## How to use it

- Update with `claude update`, or through your package manager, to get this release.
- If you use Bedrock, Vertex, Foundry, or Mantle with a model name Claude Code doesn't recognize, you'll now get the shorter system prompt by default; set `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` if you need the full one.
- No action is needed for the large-file or session fixes — they apply automatically.
