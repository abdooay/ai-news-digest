## What changed

OpenAI published guidance for business leaders on measuring whether their AI investment is actually paying off, alongside new reporting features in the ChatGPT Admin Console.

The Admin Console analytics now cover ChatGPT Work and Codex together, including:
- **Usage tracking**: active users, credit consumption, and token usage.
- **Task classification**: messages are automatically grouped into business use cases, like feature development or account research.
- **Outcome measurement**: for Codex specifically, tracking how much AI-written code contributes to merged commits and code quality.
- **Automated reporting**: an admin plugin that generates reports and dashboards for leadership.

Along with the feature, OpenAI laid out a recommended process: set baseline metrics before rolling out an AI workflow, decide up front what outcome you're measuring (speed, quality, or cost), account for the time spent reviewing and correcting AI output (not just the time it saves), and reinvest time savings into higher-value work rather than assuming they show up automatically as profit. OpenAI's own worked example: a sales team that cuts account-research prep from four hours to one hour (including review time), and reinvests half the saved time into more customer calls, could see an illustrative 245% first-year return after accounting for about $60,000 in AI costs.

## Why it matters

A common problem with rolling out AI tools inside a company is that usage numbers (messages sent, users active) don't by themselves tell you whether the tool is creating real value. This release gives administrators a way to see not just how much ChatGPT and Codex are used, but what kind of work that usage maps to, and — for code — whether it's actually landing in shipped commits. The methodology guidance is aimed at avoiding a common mistake: counting "time saved" as pure profit without accounting for the time spent reviewing AI output.

## How to use it

- Admins can find the new usage and outcome reports in the ChatGPT Admin Console, covering ChatGPT Work and Codex.
- Install the admin plugin to get automated reports and dashboards.
- Before rolling out a new AI workflow, set a baseline measurement and decide what outcome (speed, quality, cost) you're going to track, then measure again after adoption — including time spent reviewing AI output.
