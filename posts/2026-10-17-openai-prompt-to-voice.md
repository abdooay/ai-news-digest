## What changed

OpenAI added two related updates to GPT-Live, its real-time voice API, on October 16, 2026:

- **Prompt-to-voice.** You can now create a custom voice by describing it in text, through the API or the voice Playground, and reuse that voice in GPT-Live sessions. Creating the voice itself is free; actually generating speech with it still uses normal GPT-Live session billing. This is available to all API customers.
- **Nine new built-in voices.** GPT-Live added nine natural-sounding voices across five languages: Nuri, Juni, and Flitz (German); Brise and Sillage (French); Nira (Hindi); Harema and Shida (Japanese); and Noeul (Korean).

## Why it matters

GPT-Live powers real-time, spoken conversations with the API (think voice assistants or live customer-support bots). Before this, you picked from a fixed list of preset voices. Prompt-to-voice means you can describe the voice you want — for example, a calm, low-pitched narrator — and get a matching voice without manual audio design work. The new built-in voices mainly help apps serving German, French, Hindi, Japanese, or Korean-speaking users, who previously had fewer natural-sounding options in those languages.

## How to use it

- To create a custom voice from a description, use the voice-creation flow described in OpenAI's custom voices guide, either via the API or the voice Playground.
- To use one of the nine new voices, select it by name (e.g. `Nuri`, `Brise`, `Nira`) when starting a GPT-Live session, the same way you'd select any other built-in voice.
