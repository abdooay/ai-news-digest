## What changed

Claude Code, Anthropic's command-line coding agent, shipped two releases since the last digest: v2.1.271 and v2.1.272.

v2.1.271 is a large release. Highlights:

- **Fast mode in remote sessions**: "Fast mode" (a quicker-but-still-Opus-quality response setting, toggled with `/fast`) now works in Claude Code Remote sessions, both cloud-hosted and self-hosted runners, following the host's setting or a `/fast` command typed in the session, where an organization allows it.
- **Per-command network allowlists for sandboxed commands**: when Bash, PowerShell, or Monitor run in "auto" mode with sandboxing, Claude Code now reviews which internet hosts a specific command actually needs and opens network access to only those hosts for that one command, refusing everything else.
- **Mouse support in the `/config` panel**: in fullscreen mode, the mouse wheel scrolls the settings list and clicking a setting's value changes it.
- **Subagents can skip CLAUDE.md files**: a new `omitClaudeMd` option in agent frontmatter (or the `--agents` JSON) lets custom and plugin subagents run without loading user, project, and local CLAUDE.md instruction files. Files an organization pushes as managed policy still load regardless.
- **Markdown artifacts render as documents**: Markdown files published as artifacts (Claude Code's way of sharing generated files) now display as styled document pages with a title header and syntax-highlighted code, instead of plain text.
- **More concurrent artifact watching**: a session can now watch up to 10 published artifacts at once for changes made elsewhere, up from 5.
- A long list of bug fixes, including: a cached organization policy being wrongly reused after switching accounts; an enterprise MCP configuration file that couldn't be parsed being silently ignored instead of warning at startup; cloud sessions rejecting subagent tool calls after a workflow approval was applied mid-session; and several Bash permission-checking edge cases (wildcards, `cd`+`git` chains, and files read by commands like `fmt` or `column`).
- Editor and platform-specific fixes for VS Code, Claude Code on the web, Claude Tag (Claude in Slack), and Code Review — mostly reliability and display fixes rather than new features.

v2.1.272 is a small follow-up release. The changelog entry for it just says "bug fixes and reliability improvements," with no further detail published.

## Why it matters

The per-command network allowlist is the most notable security-relevant change: it narrows what a sandboxed command can reach on the network to exactly what that command needs, rather than an all-or-nothing decision, which reduces the damage a misbehaving or compromised command could do. Fast mode reaching remote sessions closes a gap between local and cloud/self-hosted use, so teams running Claude Code on shared infrastructure get the same speed option. The Markdown-as-document rendering and expanded artifact watching are smaller quality-of-life improvements for anyone using Claude Code's artifact-sharing feature.

## How to use it

- Update with `claude update`, or through your package manager, to get both releases.
- Toggle fast mode with `/fast` in a remote session, subject to your organization's settings.
- Network allowlisting for sandboxed auto-mode commands applies automatically — no configuration needed.
- Add `omitClaudeMd: true` to a custom agent's frontmatter (or the equivalent `--agents` JSON) to have it skip CLAUDE.md files.
- Everything else, including the v2.1.272 fixes, applies automatically after updating.
