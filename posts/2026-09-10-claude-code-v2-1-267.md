## What changed

Claude Code, Anthropic's command-line coding agent, shipped v2.1.267 on September 9, 2026. Highlights from a long list of changes:

**New settings:**
- `maxEffortLevel` (set globally or per model under `modelSettings`) caps how much "effort" — how much reasoning/compute a model spends per request — Claude Code will use, across every provider including Bedrock, Vertex, and Foundry. Users can still choose a lower effort level than the cap, just not a higher one.
- `--system-prompt-snapshot off` makes Claude Code render the system prompt fresh on every request, instead of reusing the version recorded at the start of the conversation. This is meant for people actively editing prompt text and wanting to see changes take effect immediately.

**Security fix:**
- Fixed a bug where a marketplace entry (a source Claude Code can fetch plugins from) with a backslash in its file path could bypass the check meant to keep fetched marketplaces contained to their own folder, on macOS and Linux.

**Reliability and prompt-cache fixes** (prompt caching lets Claude Code reuse previously-processed context instead of resending it, which saves time and money):
- Fixed several cases where resuming a session — after `/compact`, after a crash mid-tool-call, or after reloading a large (over 5 MB) transcript — could break prompt-cache reuse or drop parallel tool calls.
- Fixed cases where switching models with `/model`, an MCP server reconnecting, or a tool disappearing mid-conversation would force Claude Code to resend the whole tool list, breaking the cache instead of reusing it.
- Fixed `effort:` settings in custom commands, skills, and subagents being ignored on models whose default effort level is still fixed (Opus 4.7, Opus 4.8, and Fable 5).

**Other fixes:**
- Fixed Cowork scheduled tasks failing to start in organizations that require sandboxing.
- Fixed `/context` and other local command output appearing blank on mobile clients.
- Fixed keyboard shortcuts (shift+enter, option+backspace) breaking after reconnecting to a tmux or SSH session.
- Fixed artifact publishing so a failed upload retries once, instead of just reporting an unclear error.
- Several VS Code extension fixes: a hang at 100% CPU when editing conversations with certain saved transcripts, pasting screenshots on WSL2 inserting raw bytes instead of attaching the image, and diff views always using a dark theme regardless of the editor's actual theme.
- Several Claude Tag (Claude in Slack) fixes: clearer replies when an organization runs out of usage credits, and a fix for edit/delete requests on top-level messages not reaching the right session.

## Why it matters

The `maxEffortLevel` setting is useful for organizations that want to control API costs — it stops any user or automation from letting a model spend more compute per request than intended, no matter which cloud provider serves the request. The marketplace path-traversal fix closes a real security gap: without it, a maliciously crafted marketplace entry could potentially place files outside its intended folder. The prompt-cache fixes are mostly invisible day-to-day, but collectively they should make resumed and long-running sessions noticeably cheaper and faster, since fewer of them will silently force a full cache miss.

## How to use it

- Update with `claude update`, or through your package manager.
- To cap effort spending, set `maxEffortLevel` at the top level of your settings, or per model under `modelSettings`.
- To always see fresh system-prompt text while editing prompts, run with `--system-prompt-snapshot off`.
- The security and reliability fixes apply automatically after updating — no configuration needed.
