## What changed

Claude Code is Anthropic's command-line coding agent. Version 2.1.260, shipped September 3, 2026, is mostly fixes, with a few new features:

**New features:**
- A diff panel that opens beside the conversation in fullscreen mode, showing your uncommitted changes as Claude edits. Toggle it with `/diff`.
- `/cost` and the status line's `prompt_cache` field now show a likely reason when your prompt cache misses — for example, that tool definitions or the system prompt changed, or the session sat idle past the cache's expiry time.
- A text version of `/advisor` (`/advisor`, `/advisor <model>`, `/advisor off`) now works in the desktop app, Remote Control, and other headless sessions (the `-p` flag or the Agent SDK), not just the interactive terminal.
- `/reload-plugins` is now available in headless sessions.

**Notable fixes:**
- Fixed a bug where `Edit`/`Write`/`Read` permission rules with parentheses in the file path (like a folder named `(drafts)`) were dropped as invalid — which could leave a folder meant to be read-only actually writable.
- Fixed a related bug where one permission rule with a broken pattern (such as an unclosed `[`) made every file edit in the session fail with an "Invalid regular expression" error.
- Fixed Bash permission checks silently auto-approving certain zsh commands that hid a command substitution inside a shell variable assignment (`REPORTTIME`, `REPORTMEMORY`, or `DIRSTACKSIZE`); these now correctly prompt for approval.
- Reverted a change from the previous version (2.1.259) that had applied file-read permission rules to Bash command arguments — that change was blocking ordinary commands like `npm run build` under a `Read(./**/build/**)` rule, even outside of any restricted mode.
- Fixed `/rewind` reporting success when the backup files needed to restore a checkpoint were actually missing, so nothing was restored.
- Auto-compact (which trims old conversation history to stay under the context limit) now triggers earlier for 1-million-token-context models like Opus and Fable, and no longer times out when compacting very large conversations.

The full list of changes is long and covers many smaller sandbox, permissions, and reliability fixes; see the source link for the complete changelog entry.

## Why it matters

The permission-rule parentheses bug is the one worth knowing about even if you don't read changelogs closely: if you had a folder with parentheses in its name and a rule meant to protect it, that protection may not have been working, and file edits could fail entirely if any rule elsewhere had a bad pattern. Both are now fixed automatically once you update — no configuration change needed.

The diff panel and cache-miss diagnostics are quality-of-life improvements: the diff panel lets you watch changes happen without switching to `git diff` yourself, and the cache-miss reasons help explain unexpectedly high costs on repeated turns.

## How to use it

- Update with `claude update`, or through your package manager.
- Press `/diff` in fullscreen mode to open the new diff panel.
- Check `/cost` or the status line after a request to see why a prompt-cache miss happened, if one did.
- No action needed for the permission-rule and Bash-parsing fixes — they apply automatically after updating.
