## What changed

Claude Code, Anthropic's command-line coding agent, shipped v2.1.275 and then, the same day, a follow-up fix in v2.1.276.

**v2.1.275 highlights:**
- **Signed-in account display**: the Claude apps gateway sign-in flow now shows which account you're signed into, with a confirmation step before saving.
- **Send-now shortcut**: `ctrl+enter` or `ctrl+x ctrl+s` now interrupts the current turn and sends immediately.
- **Skill and plugin syncing**: skills and plugins you have on claude.ai now sync automatically to your terminal sessions. This can be turned off in settings.
- **`/plugin install <plugin> --marketplace <source>`**: install a plugin directly from a specific marketplace source.
- **Startup warning** for a misconfigured `otelHeadersHelper` (a setting for adding custom headers to OpenTelemetry telemetry requests).
- A long list of smaller fixes: memory file handling, subagent messaging, file suggestions, fullscreen mode display, plugin/marketplace URL handling, session resumption, vim mode, large file handling, sandboxed Bash commands, and the transcript view.

**v2.1.276** was a same-day regression fix: v2.1.275 had a bug that made every request fail with a `400 … Input tag 'advisor_20260301'` error when `ANTHROPIC_BASE_URL` pointed at a proxy or gateway. That's fixed.

## Why it matters

If you route Claude Code traffic through a proxy or LLM gateway via `ANTHROPIC_BASE_URL`, v2.1.275 briefly broke every request for you — v2.1.276 is a required update if you're on 275 and on that setup. For everyone else, the more visible changes are the send-now shortcut (useful if you often want to cut a turn short and send right away) and automatic skill/plugin syncing from claude.ai, which means custom skills and plugins now follow you between the web and the terminal without manual setup.

## How to use it

- Update with `claude update`, or through your package manager, to get to v2.1.276.
- If skill/plugin syncing from claude.ai isn't wanted, turn it off in settings — it's opt-out, not opt-in.
- Use `ctrl+enter` or `ctrl+x ctrl+s` to interrupt a turn and send immediately.
- Use `/plugin install <plugin> --marketplace <source>` to install from a specific marketplace.
