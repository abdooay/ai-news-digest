## What changed

Claude Code, Anthropic's command-line coding agent, shipped version 2.1.330. The release has dozens of entries; here are the ones that matter most:

- **Easel: automatic charts.** Claude Code now ships with "easel," a built-in mod (an extension that changes how Claude Code behaves) that draws charts when you ask for one, or automatically under results from MCP (Model Context Protocol — the standard Claude Code uses to connect to outside tools) metrics tools. It's on by default for Pro, Max, and, where available, Team and Enterprise plans on macOS and Linux. You can turn automatic charts off in `/config`.
- **Sign-in for managed organizations.** If your organization manages Claude Code through Anthropic's Enterprise Admin Console, running `claude auth login` now applies the organization's settings and uses its configured cloud provider or gateway automatically.
- **Shorter sign-in links.** The link shown by `/login`, `claude auth login`, and `claude setup-token` is now much shorter. If you need the old, full link instead — for example because a script reads a value out of it — set `CLAUDE_CODE_FULL_SIGN_IN_LINK=1`.
- **Notable fixes:** Claude Code freezing for minutes right after compacting a very long conversation is fixed; WebFetch freezing a session for minutes on some pages (or returning nothing on others) is fixed; a bug that could delete a worktree (an extra working copy of a repository) another running session was using is fixed; and a race condition that could lose settings changes when several Claude Code processes saved them at the same time is fixed.
- **A revert:** version 2.1.329 had removed the automatic retry that used to kick in when a `max_tokens` request exceeded a model's or gateway's limit. That removal is undone in 2.1.330, so the automatic retry is back.
- Many smaller fixes to Code Mode (scripted batches of tool calls), self-hosted runners, `/mcp`, `/plugin`, Grep, and Windows/Linux startup speed.

## Why it matters

Easel means you no longer need to ask Claude to write chart-drawing code by hand when looking at MCP tool results like metrics — it can draw the chart itself. The organization sign-in change removes a manual setup step for people whose company manages Claude Code centrally. The freezing and data-loss fixes matter even if you never notice them: they remove real ways the tool could previously hang or silently lose work.

## How to use it

- Update with `claude update`, or through your package manager, to get version 2.1.330.
- To turn off automatic charts, open `/config` and disable easel's automatic behavior.
- If a script of yours parses the sign-in link, add `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` to your environment to keep getting the full-length link.
- No action is needed for the bug fixes — they apply automatically once you're on this version.
