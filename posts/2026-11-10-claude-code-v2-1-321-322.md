## What changed

Claude Code, Anthropic's command-line coding agent, shipped versions 2.1.321 and 2.1.322. Highlights:

- **Claude Fable 5.2 support.** Claude Code added the new `claude-fable-5-2` model (see Anthropic's same-day announcement) and made it the default "Fable" model. Existing saved picks of Fable 5.1 move to the new default automatically — on Pro and Max plans right away, and on Team and Enterprise plans once the organization turns it on. Running `/model claude-fable-5-1` switches back to the older version.
- **Security fix: MCP OAuth secrets.** Fixed a bug where, during MCP (Model Context Protocol) sign-in, a server that redirected the request could cause secrets such as refresh tokens to be sent to a different host than intended.
- **New `--settings <file>` flag for `claude remote-control`.** This applies a chosen settings file to every session that Remote Control starts. If the file changes, no new session starts until you restart `claude remote-control`.
- **Vertex fast mode (v2.1.322).** Fast mode — faster model responses — is now available on Google Vertex in the global, US, and EU regions, falling back to standard speed if Vertex doesn't support it for a given request.
- A long list of smaller fixes, including: Bash permission checks that could run outside the sandbox or miss a file write's real folder; `cp`/`mv` commands into a directory not getting deny-rule or protected-file checks; and `NotebookEdit`/`Edit` bugs that could delete or overwrite the wrong notebook cell on network paths (UNC shares, WSL folders, `/net` mounts).

## Why it matters

The MCP OAuth fix is the one worth paying attention to: a server-side redirect during sign-in could send sensitive tokens somewhere they shouldn't go, which is exactly the kind of bug that matters if you connect Claude Code to third-party MCP servers.

Defaulting to Fable 5.2 means anyone using Claude Code's "Fable" model picks up the faster, less restrictive model automatically — see the separate Fable 5.2 digest post for what changed in the model itself.

The Vertex fast-mode addition and the Remote Control settings-file flag are both smaller quality-of-life improvements: the first brings a performance option to more cloud regions, the second makes it easier for teams to enforce consistent settings across every Remote Control session.

## How to use it

- Update with `claude update`, or through your package manager, to pick up the MCP OAuth fix.
- To keep using the older Fable model, run `/model claude-fable-5-1`.
- To apply a shared settings file to every Remote Control session, run `claude remote-control --settings <file>`.
- Fast mode on Vertex should apply automatically in the global, US, and EU regions — no setup needed.
