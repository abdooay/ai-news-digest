## What changed

Claude Code is Anthropic's command-line coding agent. Version 2.1.302 shipped with these changes:

- **New `Idle compaction` setting in `/config`.** "Compaction" is when Claude Code summarizes old conversation history to free up space. Idle compaction does this automatically while you're not typing. You can now turn it off (or back on) from `/config`, and the notice shown after an idle compaction now explains how to disable it.
- **New environment variable `CLAUDE_CODE_AUTO_MODE_MODEL`.** Auto mode is a feature that checks your tool calls for safety before running them. This variable lets you choose which model does that checking on your own machine (the "client-side" classifier). It does not affect the separate server-side classifier.
- **Standalone Claude Design is closing.** `/design-sync` and `/design-login` now show a notice that claude.ai/design, used on its own (outside Claude Code), closes on **December 14, 2026**.
- **Multiple bug fixes**, including: a "Prompt is too long" error that could appear while stopping a turn during compaction; requests failing with "Extra inputs are not permitted" after switching to Vertex or Bedrock mid-session; the Read tool no longer loading huge image files entirely into memory (files over 128 MB are now refused instead); plugin marketplaces re-cloning on every refresh under newer git versions; and a cloud session's cost/usage display resetting to zero after resuming.
- **Behavior changes**: `claude -p` (non-interactive mode) and Agent SDK sessions now default to `default` permission mode on third-party model providers unless you set `--permission-mode auto`. "Fork subagents" (a way of running a sub-task that shares context with the main conversation) are now on by default outside the terminal too; set `CLAUDE_CODE_FORK_SUBAGENT=0` to turn them off.
- **Claude Tag (Claude in Slack)** got several fixes: images in HEIC, SVG, TIFF, and BMP formats now reach Claude; links in replies no longer absorb trailing bold/italic marks; and admin settings now organize access controls into four tabs (Bundles, Connectors, Skills and plugins, Channels).

## Why it matters

Most of this release is maintenance — bug fixes for plugins, Windows file writes, and Slack integration that make day-to-day use more reliable without changing how you work. Two items are worth flagging directly: if you use standalone Claude Design (not through Claude Code), you have until December 14, 2026 to adjust, since that product is shutting down. And if idle compaction has been cutting into your context unexpectedly, you can now turn it off from `/config`.

## How to use it

- Update with `claude update`, or through your package manager.
- To stop automatic idle compaction, open `/config` and turn off the new `Idle compaction` row.
- To pick the model used for the local safety-check classifier, set `CLAUDE_CODE_AUTO_MODE_MODEL`.
- If you use claude.ai/design standalone, start migrating that work before December 14, 2026.
