## What changed

Claude Code (Anthropic's command-line coding agent) shipped v2.1.280. The main changes:

- **Claude Opus 5.5 is now the default Opus model** (`claude-opus-5-5`), with its 1 million token context window and updated pricing ($4 per million input tokens, $20 per million output tokens, $0.20 per million for cached-content reads).
- **Mouse support** was extended: you can now scroll the `/skills` list with the mouse wheel, and click a skill's state options inside `/plugin`, when running Claude Code in fullscreen mode.
- A new environment variable, `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH`, lets you raise or lower the 2,048-character limit on descriptions and instructions sent by MCP servers (Model Context Protocol servers — external tools Claude Code can connect to).
- Telemetry (usage/monitoring data) now includes hook output sizes and how many hook outputs were too large to record in full.

Notable bug fixes:
- **Auto mode** (Claude Code's automatic effort-level picker) had two stuck-loop bugs: it could retry the same action over and over after a safety check declined to review it, and it could deny actions repeatedly with no pause when a safety check gave no answer. Both are fixed — a declined-review action is now denied once with an explanation, and repeated no-answer cases now back off and stop the turn after ten in a row with a message.
- A security-relevant fix: writes made through a symlink (a file that points to another file or folder) were being checked against the symlink's own location in the project, not where the write actually lands. This meant permission rules like auto-approve or allow-lists could wrongly approve a write that actually lands outside the intended folder. It's now checked correctly.
- Several keyboard and dialog bugs: pressing Ctrl+C or Ctrl+D twice in dialogs like `/model` or `/config` used to quit Claude Code entirely instead of just closing the dialog; a stray `y` or `n` keypress used to confirm or cancel dialogs unintentionally; and typing letters, digits, or spaces in text fields could get eaten by an unrelated keyboard shortcut.
- Several stability fixes: conversations failing every turn because of malformed message history, a crash when resuming a session with a damaged saved transcript, and Claude Code hanging if a settings file was replaced by a named pipe (a special kind of file) while being read.
- A text-handling fix for Persian and Arabic: the zero-width non-joiner character (an invisible character used to join parts of a word, such as forming a plural) was being incorrectly stripped out as junk.

## Why it matters

The auto mode retry-loop fixes matter most for anyone running Claude Code with less supervision (auto mode makes its own effort-level decisions): a stuck loop that keeps retrying or keeps silently denying actions could previously burn time or tokens without making progress. The symlink write-permission fix closes a real gap — a project set up to auto-approve writes to certain files could previously have that trust extended to a different, unintended location through a symlink.

## How to use it

- Update with `claude update`, or through whatever package manager you installed Claude Code with, to reach v2.1.280.
- No action is needed to pick up Opus 5.5 as the new Opus default; if you rely on the exact previous default, check your model configuration in `/model`.
- If you use `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH`-sensitive MCP servers with very long descriptions, set that variable to raise the cap.
