## What changed

On September 1, 2026, OpenAI published an article using its "Enterprise Signals" data (usage statistics from business customers) to argue that companies are splitting into two groups: those using AI as an occasional assistant, and those rebuilding workflows so AI agents do the work end-to-end on their own ("autonomous execution").

The headline number: the top 10% of business AI users ("frontier companies") now generate 8.3 times as many output tokens per active user as typical companies, up from 2.6 times in January 2026. ("Output tokens" is a rough measure of how much work an AI model is actually doing for a user — more output generally means the AI is doing more of the task, not just answering a quick question.)

OpenAI gave three named examples:
- **Basis** (an accounting company) uses an AI agent called Codex to automate new-employee setup tasks, cutting first-day onboarding from two hours to 30 minutes.
- **Clay** (a sales tool company) runs a separate AI "subagent" for each customer account overnight, pulling together scattered deal information and producing a daily list of priority actions for its sales team.
- **Exa Labs** (a search API company) has Codex watch its code repositories for integration opportunities, then automatically write pull requests, run tests, and prepare updates — cutting down on handoffs between teams.

OpenAI also laid out six steps it recommends for companies trying to do this: pick high-impact workflows, define measurable goals, clearly define what the AI agent is responsible for, build supporting processes for the humans working alongside it, make successful experiments reusable, and scale the patterns that work.

## Why it matters

This is OpenAI's own usage data, so treat the "8.3x" figure as a data point from a company selling these tools, not independent research. That said, the underlying trend — a growing gap between companies that just use AI chat as a helper and companies that redesign a workflow so an agent runs it — is a useful thing for any team evaluating how deeply to adopt these tools to think about. The named examples (Basis, Clay, Exa Labs) give concrete before/after detail rather than vague claims, which makes them easier to evaluate.

## How to use it

- If you're deciding how to roll out AI agents at your company, OpenAI's suggested order is: start with one high-impact workflow, define what "success" looks like in numbers before you start, and make sure people know exactly what the agent is and isn't responsible for.
- Look at the three examples for patterns you could reuse: automating a repetitive onboarding checklist (like Basis), running an overnight per-account summary job (like Clay), or having an agent watch a codebase for a specific kind of opportunity and open pull requests (like Exa Labs).
