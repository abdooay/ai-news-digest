## What changed

Claude Code, Anthropic's command-line coding agent, shipped v2.1.268 on September 10, 2026. It's a large release; here are the highlights.

**Gateway and admin features** (a "gateway" is a self-hosted proxy an organization runs so it can route and monitor its team's Claude Code traffic):
- When an organization sets `pricing:` in its gateway config, signed-in clients now receive the same rates through managed settings, so the `/cost` command and usage telemetry match what the organization is actually being charged.
- Gateways now warn on startup if `access_control.allow_cidrs` (the list of IP ranges allowed to connect) is empty, and warn once the first time a request arrives from a public IP address.
- A new `gatewayInternalNetworks` setting lets administrators allow `/login` from their organization's own public IPv4 addresses.
- `claude self-hosted-runner --remove-session-state` (off by default) deletes a session's temporary files once the session ends.

**Security fix:**
- Fixed a bug where a turn could fail with an HTTP 400 error on third-party Anthropic-compatible endpoints (set via `ANTHROPIC_BASE_URL`), caused by a regular expression in the Artifact tool's input schema that those endpoints rejected. This has been happening since v2.1.265.

**Other notable fixes:**
- Fixed `WebFetch` hanging forever when a server kept a connection open without ever finishing its response; fetches now time out after 300 seconds (configurable with `CLAUDE_CODE_WEBFETCH_DEADLINE_MS`).
- Fixed permission rules (deny/ask) on symlinked system directories not applying when a path was given by its real (non-symlink) location.
- Fixed several prompt-caching bugs: resuming after `/compact`, after a crash mid-tool-call, or after reloading a large transcript could silently break cache reuse or drop tool calls.
- Fixed plugin and MCP server errors that could leak secrets — tokens in git source URLs, or values resolved from `${VAR}` placeholders — into error messages.
- [VS Code] Fixed a hang at 100% CPU when editing conversations with certain transcripts, and diff views always using a dark theme regardless of the actual editor theme.
- [Claude Code on the web] Fixed cloud sessions running longer than about six hours silently losing files saved to persisted folders; saves now persist for up to a day.
- [Claude Tag / Claude in Slack] Several fixes, including a channel's long-running session no longer getting replaced mid-conversation, and clearer explanations when an action is blocked by a permission rule.
- [Code Review] Fixed reviews sometimes ending as "incomplete" when a verification step failed partway through; the review now retries with a fresh agent and reaches a verdict.

## Why it matters

The gateway pricing sync and the IP-allowlist warnings are aimed at organizations running Claude Code through their own infrastructure — they make it easier to keep spend visibility accurate and to notice a misconfigured gateway before it becomes a security problem. The Artifact tool security fix matters for anyone using a third-party Anthropic-compatible API endpoint instead of Anthropic's own: those setups were completely broken (every turn failing) since v2.1.265, so this release fixes a real regression, not just a nice-to-have. The prompt-cache and secret-leak fixes are mostly invisible day to day but reduce wasted cost and the chance of an accidental credential leak in logs.

## How to use it

- Update with `claude update`, or through your package manager.
- To sync spend rates from a gateway, set `pricing:` in your `gateway.yaml`.
- To allow `/login` on your organization's own public IPs, set the `gatewayInternalNetworks` managed setting.
- To change the WebFetch timeout, set `CLAUDE_CODE_WEBFETCH_DEADLINE_MS` (0 disables it).
- Everything else applies automatically after updating — no configuration needed.
