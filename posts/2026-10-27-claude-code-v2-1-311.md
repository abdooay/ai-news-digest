## What changed

Claude Code is Anthropic's command-line coding agent. Version 2.1.311 includes:

- Two new flags for the self-hosted runner: `--hold-idle-file` and `--max-hold-min`, which control how long an idle runner process is kept alive.
- A new tip shown in the "Explanatory" output style (a mode where Claude explains its reasoning as it works), which now points users toward it when they ask Claude for explanations.
- VS Code syntax coloring for code blocks shown in chat, plus improvements to Claude Tag (Claude in Slack) and `/code-review`.

It also fixes several bugs:
- Startup and file-read freezes caused by very long lists in a project's `CLAUDE.md` file (the file Claude Code reads for project-specific instructions).
- Delays when interrupting Claude mid-response.
- Context overflow on sessions using the 1M-token context window — these now automatically compact (summarize older parts of the conversation) and continue instead of failing.
- Several issues affecting MCP servers (external tool integrations), subagents, memory files, and Remote Control (managing a Claude Code session from your phone or another device).

One behavior change: `ultrathink` (Claude Code's deepest-thinking mode) now runs at "xhigh" effort — the highest available reasoning-effort setting — on several models, including Opus 5.5, in the interactive terminal. Ctrl+D behavior in the agent view also changed.

## Why it matters

The startup and file-read freeze fixes matter most for anyone working in a large repository with a long `CLAUDE.md` file — that bug could make Claude Code hang before you could even start working. The 1M-context fix is useful if you rely on very long sessions: instead of the session failing outright on context overflow, it now compacts automatically and keeps going.

Running `ultrathink` at xhigh effort means deep-thinking requests now use more reasoning before answering, which can produce better results on hard problems — at the cost of being slower and using more tokens, since effort level affects how much the model "thinks" before responding.

## How to use it

- Update with `claude update`, or through your package manager, to get this release.
- No configuration changes are required for the bug fixes.
- If you run Claude Code through a self-hosted runner, check the new `--hold-idle-file` and `--max-hold-min` flags if you want finer control over idle runner lifetime.
- Try `ultrathink` on a hard problem to see the new xhigh-effort behavior on supported models.
