## What changed

Claude Code, Anthropic's command-line coding agent, shipped v2.1.331. It is mostly bug fixes, plus a few small features:

- **Code Mode on more cloud providers**: Code Mode (a mode where Claude writes and runs short scripts in a terminal session instead of calling tools one at a time) now works on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and Claude Platform on AWS.
- **`claude doctor` API check**: the `claude doctor` diagnostic command now has a section that reports whether it can reach the API, showing the HTTP status, the error, or why the check wasn't run.
- A new `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION` environment variable, for use behind a proxy that cuts off compressed responses early (not yet recommended for self-hosted runners or Remote Control).
- Plugin manifests can now list `optionalDependencies`: plugins that install alongside the main plugin and can be disabled or uninstalled separately.
- A long list of bug fixes, including: MCP tool calls that could hang for up to 30 minutes on a malformed reply from a local or WebSocket server; `/compact` and auto-compact sometimes losing part of the conversation summary; Stop hooks in Claude Desktop missing the model's last reply; Code Mode losing the middle of long script output; and a crash when a custom API endpoint returned a tool call with no name.

## Why it matters

The Code Mode expansion means teams running Claude Code through a cloud provider other than the Claude API directly (Bedrock, Google Cloud, Foundry, or AWS) can now use the same faster, script-based tool-calling mode that was previously limited to direct API users. The `claude doctor` API check makes it faster to tell whether a problem is a broken network path or something else, instead of guessing from a failed session. The bug fixes address real but narrow failure cases — most users won't have hit them, but anyone who has will likely recognize their issue in this list.

## How to use it

- Update with `claude update`, or through your package manager, to reach v2.1.331.
- If you run Claude Code on Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, or Claude Platform on AWS, Code Mode is now available in terminal sessions there with no extra setup.
- Run `claude doctor` to see the new API connectivity section.
- If you're behind a proxy that cuts off compressed responses, try `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION=1` (not for self-hosted runners or Remote Control yet).
