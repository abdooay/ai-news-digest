## What changed

Claude Code, Anthropic's command-line coding agent, released version 2.1.221 on August 4, 2026.

**New features:**
- **Focus view** (VS Code): a chat-menu toggle, `Ctrl+Alt+F`, that hides the stream of tool activity behind an expandable per-turn summary, with a small live indicator showing a tool is still running.
- **Masked credential files**: a new `mode: "mask"` setting for sandbox credential files on Linux and WSL. Sandboxed commands see a stand-in ("sentinel") value instead of the real secret — either the whole file or just the parts matched by a regex — while Claude Code's sandbox proxy swaps in the real value only when the request actually leaves the sandbox. On macOS this still falls back to fully denying access to the file.
- `claude plugin validate` now warns when a plugin or marketplace name would be rejected by Claude Desktop's managed marketplace sync.
- A new `prompt-audit` subcommand in the `claude-api` skill audits prompts and tool descriptions for patterns written for older, now-outdated models.

**Security and correctness fixes:**
- Fixed a Bash tool permission-check bypass: zsh could run hidden commands inside `[[ ]]` regex conditionals without triggering a permission prompt. Affected commands now prompt correctly.
- Fixed PowerShell permission checks mishandling Windows paths that contain quote characters; those paths now correctly prompt for approval instead of slipping through.
- Fixed the "thinking" toggle having no effect for the rest of a session if that session started with thinking turned off.
- Fixed MCP (Model Context Protocol) servers passed via `--mcp-config` not being connected before the first turn in print mode (`-p`), which caused the model to output tool calls as plain text instead of actually calling them.
- Fixed WebSearch failing with a 400 error at effort `xhigh`/`max` when thinking is disabled.
- Fixed sandboxed large file uploads failing with TLS errors when going through the sandbox network proxy.

**Other notable changes:**
- Background sessions now commit and push their work to preserve it, only open a draft pull request when the task calls for one, follow the project's CLAUDE.md git instructions, and always report where the work ended up.
- `/plugin install` now refreshes a stale plugin marketplace listing and retries before reporting a plugin as not found.
- Plugins installed via `/plugin` now activate immediately when it's safe to do so, instead of always requiring a manual `/reload-plugins`.
- `/status` now shows whether a session is interactive or a background job, and if a background job, whether it is attached or unattended.
- The Stats panel now counts cache tokens in its totals, broken down by input, output, cache read, and cache write.

## Why it matters

The zsh and PowerShell permission fixes close real gaps where a command could run without the user being asked to approve it first — worth updating for on their own. Focus view and the masked-credential mode are both about reducing noise and risk in everyday use: Focus view cuts down on scrolling through raw tool output, and masked credentials let a sandboxed command use a secret (like an API key) without that secret ever being visible in the sandbox itself.

## How to use it

- Update with `claude update`, or through your package manager.
- Toggle Focus view in VS Code with `Ctrl+Alt+F`, or run the "Claude Code: Toggle Focus view" command.
- To mask a credential file instead of denying access to it, set `mode: "mask"` on that file's sandbox credential configuration (Linux/WSL only).
- No action needed for the security fixes — they apply automatically after updating.
