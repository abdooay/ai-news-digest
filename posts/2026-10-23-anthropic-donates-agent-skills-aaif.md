## What changed

Anthropic announced it is donating Agent Skills — its open standard for giving AI agents specialized knowledge and step-by-step workflows — to the Agentic AI Foundation (AAIF), a project under the Linux Foundation. The donation covers the Agent Skills standard itself, its name and logo, its GitHub organization, and the agentskills.io domain.

A "skill" in this standard is a folder with a `SKILL.md` file that teaches an AI agent how to do a specific task, plus any extra scripts or reference files it needs. Anthropic built the idea while making Claude Code, its command-line coding agent, after noticing that agents were good at general knowledge work but often missing the specific procedural know-how a real business task needs.

Since Anthropic published the standard openly in December 2025, people have published about 1 million skills, with close to 280 million installs. More than 70 agent platforms — including ChatGPT, Cursor, GitHub Copilot, and VS Code — have added support for it.

The AAIF is a neutral home Anthropic co-founded last year with Block and OpenAI. Anthropic already donated its other agent standard, the Model Context Protocol (MCP, a way for agents to connect to external tools and data), to the same foundation.

## Why it matters

Handing a widely-used standard to a neutral foundation, rather than keeping it under one company's control, matters if you build on it: the standard's future direction will now be set by a community process, not by Anthropic alone. The announcement says engineers from Anthropic, Google, OpenAI, and other companies will maintain it as individuals going forward, with David Soria Parra and Mahesh Murag as Lead Maintainers.

This doesn't change anything about skills you already use or have written — it's a governance change, not a technical one.

## How to use it

- Nothing you need to do to keep using or writing skills — this is a change in who stewards the standard, not in how it works.
- To give feedback on proposed changes to the standard, join the project's Discord (linked from agentskills.io).
- To follow or contribute to the spec directly, see the GitHub organization at github.com/agentskills/agentskills.
- Anthropic has proposed next steps including versioned releases, a formal process for proposing changes, and security guidance for people who write and install skills — no dates have been set for these yet.
